11. **Hotfix: Pencegahan Crash TypeError 'inferred.join is not a function' (Part 7)**:
    - **Akar Masalah**:
      - Ketika AI mengembalikan objek `visualDna` dengan properti `inferred` (atau `observed`, `anchors`, `editableVariables`, `variables`, `metaphor`) sebagai string mentah (atau objek/undefined) alih-alih `string[]`, pemanggilan langsung `.join(', ')` di JSX memicu runtime crash tak tertangani: `TypeError: O.inferred.join is not a function`.
      - Data sesi yang rusak ini tersimpan ke IndexedDB, sehingga setiap kali halaman di-refresh, ErrorBoundary React langsung aktif.
    - **Penyelesaian Berlapis (Multi-Tier Defense)**:
      1. `lib/prompt-agent/engine.ts`: Mengimplementasikan `normalizeVisualDna(raw: unknown): VisualDNAProfile | null` yang menjamin seluruh properti array visual DNA (`observed`, `inferred`, `anchors`, `editableVariables`, `metaphor`, `symbolism`) selalu bertipe `string[]`, terlepas dari apakah input bertipe string, koma, baris baru, maupun objek.
      2. `lib/prompt-agent/client.ts`: Normalisasi otomatis diterapkan langsung saat parsing respons dari API prompt agent.
      3. `lib/prompt-agent/store.ts`: Normalisasi diterapkan saat memuat sesi aktif (`loadActivePromptSession`), riwayat sesi (`loadPromptSessions`), dan sesi per-ID (`getPromptSession`), membersihkan data lama secara transparan.
      4. `components/PromptGeneratorView.tsx`: Mengganti seluruh `.join()` langsung pada rendering visual DNA dengan fungsi pembungkus `safeFormatList(val, fallback)`, memastikan UI 100% tahan banting terhadap tipe data apa pun.
    - **Testing & Production Deployment**:
      - 105/105 unit tests lulus (`pnpm test:run`), termasuk suite tes normalisasi visual DNA dan recovery sesi legacy.
