- **Analisis & Rencana Optimasi Upload FTP**:
  - Mengidentifikasi 3 bottleneck utama pada proses FTP:
    1. Buka-tutup koneksi SSH/FTPS per file (overhead handshake 1-2 detik per file).
    2. Antrean upload 1-per-1 (concurrency = 1) ditambah delay 800ms.
    3. Penyuntikan metadata biner in-memory sebelum upload.
  - Merancang solusi: *Persistent Connection Session Pool*, *Controlled Concurrency (2-3 worker)*, dan *Metadata Pipelining*.
