    - Idle TTL 60 detik untuk auto-disconnect ramah server agensi.
    - Auto-reconnect & retry otomatis jika terjadi ECONNRESET/stale connection.

  - **Controlled Concurrency di Frontend** di `components/FtpQueueView.tsx`:
    - Multi-worker queue loop (1x Serial, 2x Optimal, 3x Turbo) dengan persistent UI selector.
    - Inter-file delay dipangkas dari 800ms menjadi 50ms per worker.
