## Accomplishments

### 1. Cloudflare Pages Static Build & Deployment
- Dibuat script `scripts/build-pages.mjs` untuk isolasi rute API Node sebelum `next build` dengan `NEXT_EXPORT=true` menghasilkan bundle statis di folder `out/`.
- Deployed ke Cloudflare Pages (`https://meta-gen-gue.pages.dev`).

### 2. MetaGen Local FTP Bridge (`ftp-bridge/server.mjs`)
- Dibuat server backend lokal mandiri berbasis Node.js pada port `45678`.
- Fitur utama:
  - SFTP client (`ssh2-sftp-client`) & FTP/FTPS client (`basic-ftp`).
  - Auto-embed biner IPTC/XMP lokal via ExifTool / stream sebelum dikirim.
  - Endpoint health check `/health` & `/api/status`.
  - Endpoint upload `/api/ftp/upload` dan test koneksi `/api/ftp/test`.
  - Mendukung Private Network Access (PNA) dan header CORS penuh dari HTTPS.

### 3. Pemulihan Kredensial Microstock dari Edge LevelDB & Sinkronisasi Lintas-Domain

### 4. Background Upload & Keep-Alive Tab State
- Mengubah arsitektur tab di `app/page.tsx` dari *conditional unmounting* menjadi wrapper CSS `block` / `hidden`. Komponen antrean (`FtpQueueView`) sekarang tetap hidup di memori saat pengguna membuka Studio, Riwayat, atau Kelola Akun.
- Di `components/FtpQueueView.tsx`:
  - Menjaga state queue saat re-scan: status `success`, `uploading`, dan `error` tidak lagi ditimpa menjadi `pending`.
  - Mengamankan loop upload dengan `isUploadingRef` dan `AbortController`.
  - Menambahkan tombol "Hentikan" (Cancel) saat proses upload berjalan.
  - Menambahkan proteksi `beforeunload` saat upload aktif.
- Menambahkan indikator live pada tombol tab (spinner + hitungan `Mengunggah (2/6)` + pulsing dot), badge pada Side Rail, serta widget mengambang interaktif di pojok kanan bawah.

### 5. Windows Silent Auto-Start & Global CLI Tool
- Dibuat `ftp-bridge/run-hidden.vbs` menggunakan Windows Script Host (`WshShell.Run ..., 0, False`) agar bridge berjalan 100% senyap di latar belakang tanpa jendela CMD hitam.
- Dibuat script batch praktis:
  - `install-autostart.bat`: Memasang runner ke folder Windows Startup (`%APPDATA%\...\Startup`).
  - `uninstall-autostart.bat`: Menghapus runner dan mematikan proses aktif.
  - `check-status.bat`: Memeriksa status dan uptime bridge.
- Ditambahkan field `"bin"` pada `package.json` dan dibuat CLI global `ftp-bridge/cli.mjs`:
  - Perintah `metagen-bridge status`, `start`, `stop`, `install`, `uninstall`.
  - Didaftarkan ke sistem via `npm link`.
- Dibuat script instalasi 1-baris dari GitHub `install.ps1`:
  - `irm https://raw.githubusercontent.com/aronisme/meta-gen-gue/main/install.ps1 | iex`.
