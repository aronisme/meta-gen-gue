# Sesi Kerja 2026-10-12

## Ringkasan Pencapaian Utama

1. **Perbaikan Deadlock & Freeze Generasi Video (0% Progress Bug)**:
   - Menemukan akar masalah pada `requestVideoFrameCallback()` di `lib/video.ts` yang tidak pernah dipanggil pada video berstatus `paused` di DOM tersembunyi.
   - Menggantinya dengan event listener standar `seeked` sekali pakai, buffer delay 40ms, dan fail-safe timeout.
   - Mengoptimasi ekstraksi frame ke 640px JPEG 0.75 dan routing model multimodal langsung di GAS Proxy.

2. **Perbaikan Fatal Bug Upload Duplikat di Modal FTP**:
   - Memperbaiki race condition antara scanning duplikasi dan klik tombol "Mulai Upload".
   - Duplikat otomatis uncheck secara default jika "Lewati duplikat" aktif.
   - Menambahkan runtime pre-flight verification tepat sebelum payload dikirim ke jaringan.
   - Tombol otomatis disabled jika semua item terpilih adalah duplikat.

3. **Retensi File Fisik Sesi Aktif untuk FTP Upload**:
   - Menyimpan referensi file biner di `sessionFiles` pada `app/page.tsx` sehingga pengguna tidak perlu memilih ulang file setelah proses generate selesai.
   - Menambahkan opsi "Pilih 1 Folder (Auto-Match)" untuk kemudahan memasangkan file pada sesi tersimpan.

4. **Injeksi Lossless Metadata Biner (IPTC & XMP) & Transparansi Pengguna**:
   - Membangun injector biner lossless di `lib/metadata/embed.ts`:
     - **JPEG**: Photoshop IPTC-IIM (Record 2) + Adobe XMP Packet (APP1 Dublin Core).
     - **PNG**: Adobe XMP Packet via chunk `iTXt` (`XML:com.adobe.xmp`).
     - **Video**: Metadata via CSV Pendamping (agar codec video tidak korup).
   - Mengintegrasikan penanaman metadata otomatis di endpoint `app/api/ftp/upload/route.ts`.
   - Menambahkan transparansi penuh di UI:
     - Toggle `Tanam Metadata [IPTC & XMP]` di toolbar.
     - Bar penjelasan alur metadata di header modal FTP.
     - Badge format file pada tabel antrean (`🏷️ JPEG: IPTC & XMP Siap Ditanam`, dll.).
     - Badge kesiapan format pada kartu Studio (`🏷️ JPG: IPTC & XMP Ready`, dll.).
     - Status detail upload (`✓ Sukses (Metadata Tertanam)`).

5. **Kualitas & Verifikasi**:
   - 50/50 test Vitest lulus (termasuk 6 unit test baru di `lib/__tests__/embed.test.ts`).
   - TypeScript compilation lolos tanpa error (`npx tsc --noEmit`).
