### 2. Perbaikan Fungsionalitas Tombol "Agent Batch" ([components/PromptGeneratorView.tsx](file:///c:/App%20Tools/meta-gen-gue/components/PromptGeneratorView.tsx))
- **Akar Masalah**: Tombol dipasang kondisi `disabled={prompts.every((p) => p.generatedImageUrl)}` dan kuotanya dihitung dari `prompts.filter((p) => !p.generatedImageUrl).length`. Akibatnya, saat seluruh prompt dalam sesi sudah memiliki gambar (atau dimuat dari riwayat sesi), tombol menjadi `disabled={true}` dan menampilkan `Agent Batch (0)`, sehingga tidak dapat diklik.
- **Solusi**:
  - Tombol kini hanya dinonaktifkan jika sesi benar-benar kosong (`disabled={prompts.length === 0}`).
  - Jika seluruh prompt sudah memiliki gambar, sistem secara cerdas beralih mengambil prompt sesi yang aktif (maksimal 3–5 adegan) sehingga tombol selalu dapat digunakan.
  - Menambahkan fungsi helper `copyToClipboardSafe` dengan fallback transparan ke `document.execCommand('copy')` saat `navigator.clipboard` terhalang perizinan browser.
  - Menambahkan umpan balik visual instan: ikon berganti menjadi `<Check />` dan teks menjadi `Tersalin (X)` selama 2.5 detik.
  - Menambahkan tombol aksi interaktif `⚡ Kirim ke Flow` pada toast notification untuk memicu `handleSendFlowAgentBatchDirect`.

### 3. Analisis & Resolusi Multi-Scene Google Flow Agent Mode ([extension/flow-bridge.js](file:///c:/App%20Tools/meta-gen-gue/extension/flow-bridge.js), [components/PromptGeneratorView.tsx](file:///c:/App%20Tools/meta-gen-gue/components/PromptGeneratorView.tsx), [extension/background.js](file:///c:/App%20Tools/meta-gen-gue/extension/background.js), [extension/content.js](file:///c:/App%20Tools/meta-gen-gue/extension/content.js))
- **Akar Masalah**:
  - Pengguna mengirim instruksi multi-scene ke Google Flow Agent (misal: Scene 1 *Low-angle boats*, Scene 2 *Top-down aerial boats*).
  - Google Flow menghasilkan 2 baris kanvas terpisah, masing-masing dengan prompt teks uniknya sendiri.
  - Bridge sebelumnya mengasumsikan setiap kali gambar baru > 1, itu adalah **variasi dari prompt pertama**, sehingga melabeli baris atas sebagai `#1 (A)` dan baris bawah sebagai `#1 (B)`.
  - Di Studio, Kartu #1 menampung kedua gambar sebagai `[Var A]` dan `[Var B]`, sementara Kartu #2 tetap kosong (*unrendered*).
- **Solusi yang Diterapkan**:
  1. **Pencocokan Semantik Cerdas (`findBestMatchingScene`)**:
     - `extension/flow-bridge.js` membaca teks prompt aktual tiap baris canvas menggunakan `extractTilePromptText()`.
     - Mencocokkan teks tersebut ke array `scenes` yang dikirim dari Studio berdasarkan substring dan tumpang tindih kata kunci (*keyword overlap*).
     - Kartu atas (*Top-down aerial*) otomatis dipetakan ke Scene 2 dan diberi badge **`⚡ MetaGen #2`**.
     - Kartu bawah (*Low-angle shot*) otomatis dipetakan ke Scene 1 dan diberi badge **`⚡ MetaGen #1`**.
     - Sub-variasi huruf `(A)`, `(B)` ditiadakan jika baris canvas memiliki prompt yang berbeda.
  2. **Multi-Card Result Grouping**:
     - Bridge mengelompokkan gambar hasil unduhan berdasarkan `cardId` ke dalam array `results: [...]`.
     - Listener `METAGEN_FLOW_GEN_RESULT` di `PromptGeneratorView.tsx` memperbarui seluruh kartu target secara simultan dan independen.
  3. **Dukungan Manual Copy-Paste ke Flow Agent Chat**:
     - Menambahkan event bridge `METAGEN_REGISTER_AGENT_SCENES` yang menyimpan daftar adegan aktif ke `chrome.storage.local` (`metagen_agent_scenes`) saat pengguna menekan tombol salin.
     - Fungsi `hydrateFlowBadges()` secara periodik mendeteksi kartu adegan yang baru selesai dibuat di kanvas Flow (bahkan saat di-paste manual), menempelkan badge yang sesuai, dan menyiarkan `FLOW_CARD_DISCOVERED` kembali ke Meta-Gen Studio.
